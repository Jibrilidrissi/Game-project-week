Wij hebben de komende project weken 8 dagen school waarin wij ons gaan focusen om ons idee voor een game realiteit te maken wij zijn leergierig opzoek om dit product van hoogst moeglijke kwaliteit te maken.
Het idee is om een horizontale running game te maken met een stickman als character en natuurlijke objecten als obstakels te hebben waar je over heen en onder door moet manouvreren, dus heb je het in je om een echte stick runner te worden blijf dan op de hoogte!
